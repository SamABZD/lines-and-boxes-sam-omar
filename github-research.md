# Dots and Boxes references

- [RF-01/Dots-and-Boxes-Game](https://github.com/RF-01/Dots-and-Boxes-Game) uses the same 4x5 grid of boxes and four-coordinate input in a single C file.
- [ziadhishamali/Dots-and-Boxes](https://github.com/ziadhishamali/Dots-and-Boxes) splits the game across files and uses Windows console functions.
- [AbdelrahmanElmeniawy/Dots-and-Boxes](https://github.com/AbdelrahmanElmeniawy/Dots-and-Boxes) uses Windows headers and console colors.
- [MbfcM/Dots-and-Boxes](https://github.com/MbfcM/Dots-and-Boxes) puts the game in one source file and uses Windows console commands.

This project uses standard C terminal input and output. The board, turn logic, input parser, and terminal interface each have their own source file.
